Define:
- In english, there are 4 Main word Classes:
| Vietnamese | English | Example |
| :--- | :--- | :--- |
| Danh từ | Noun (N) | company, student, information |
| Động từ | Verb (V) | work, study, develop |
| Tính từ | Adjective (Adj) | good, important, successful |
| Trạng từ | Adverb (Adv) | quickly, carefully, successfully |

---
1. Noun -Danh từ

 A Noun name a persons, place, thing, or idea
  ex: the company hired a new employee.

- Company : Noun
- Employee: Noun

Common endings for Noun:
Look for:
- tion -> information, organization
- ment -> management, devolopment
- ness -> happiness, business
- ity -> ability, responsibility
- ance/ ence ->importance, difference

---
2. Verb -Động từ
A verb describes an actione or state
 Ex: the employee work every day

work, study, develop, manage => verb

Common endings:
Looking for:
- ize : organize, realize
- ify : indentify, simplify
- en : strenghen, widen
---

3. Adjective - Tính từ
An adjective describes a Noun 
 Ex: she is successfull manager

- successful : adjective
- Manager : Noun

Common endings:
- ful => useful, successful
- les => useless, careless
- ive => effective, attractive
- al => professional, personal
- ous => dangerous, famous

---
4. adverb-trạng từ
An adverb usually describes a verb, adjective, or another adverb
 EX: he works carefully

- carefully => arverbs
- works => verb

Common ending:

adjective + ly => adverb
careful => carefully
quick => quickly
successful => successfully

VERY IMPORTANT for TOIEC:
A useful pattern is: 

Noun => verb => adjective => adverb

Ex : success => successed => successful => successfully
